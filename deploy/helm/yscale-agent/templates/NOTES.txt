=== Upgrading from a chart older than 0.2.0 ===

Two changes need a look before you roll this out:

1. The bootstrap/storage endpoint no longer binds all interfaces. It mints
   kubelet bootstrap tokens and signs bucket URLs, and on a Pod a wildcard
   bind published both on the cluster pod IP where the tailnet ACL cannot
   reach (SECURITY-REVIEW.md H3). The default now binds loopback and
   `tailscale serve` forwards inbound tailnet TCP to it — bursts reaching the
   Connector by MagicDNS are unaffected. Anything that dialled the agent Pod's
   cluster IP on :{{ .Values.bootstrap.port }} directly will stop working.
   Restore the old behaviour explicitly if you truly need it:
     --set bootstrap.listenMode=custom --set bootstrap.listenAddress=0.0.0.0:{{ .Values.bootstrap.port }}

2. Storage signing now needs rbac.allowedNamespaces to list every namespace
   whose workloads use spec.storage, including on scope: cluster installs.
   Without it the Connector has no Secret read permission and signing fails.

A Connector image older than this chart still works: it reads
-bootstrap-listen=127.0.0.1:{{ .Values.bootstrap.port }} as a plain bind address.
A newer image under an older chart works too — a bare :{{ .Values.bootstrap.port }}
resolves to the tailnet address, or loopback when tailscaled has none.
